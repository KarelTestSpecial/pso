# PSO Project

Dit project gebruikt [Vite](https://vitejs.dev/) als ontwikkelomgeving.

## Vereisten

*   **Node.js**: v22+
*   **Package Manager**: `pnpm` (zoals vereist voor dit systeem)

## Installatie

Installeer eerst de dependencies:

```bash
pnpm install
```

## Gebruik

Start de ontwikkelserver:

```bash
pnpm dev
```

Dit start de applicatie op, meestal op `http://localhost:5173`.
Gebruik `Ctrl+C` om de server te stoppen.

### Andere commando's

*   `pnpm build`: Bouwt de applicatie voor productie.
*   `pnpm preview`: Bekijk de productie-build lokaal.
